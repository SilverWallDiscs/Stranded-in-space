# EVENTOS DE SILVER
# Estos eventos solo aparecen cuando Silver viaja contigo.

[EVENT]
name: Una mejora para la red
type: question
weight: 3
requires companion: yes
background: none

[MESSAGE]
Silver se acerca a la computadora con una idea.

"Si quieres intento programar mejor la red. Podria conseguir dos comidas durante los proximos tres lanzamientos, pero necesito usar la computadora. Que dices?"

[CHOICE]
text: Dejar que lo intente
description: Silver trabaja un rato. Hay un 35% de posibilidades de que la computadora se rompa, pero la mejora se aplica igualmente.
requires item: computer
consume chance: 35%
trigger: upgrade red
rewards: none
result: "Listo! La red esta mejorada. Si algo se rompio... bueno, podemos arreglarlo despues."

[CHOICE]
text: Mejor no arriesgarla
description: Prefieres conservar la computadora como esta.
requires item: none
consume chance: 0%
trigger: none
rewards: none
result: "Tiene sentido. Podemos intentarlo cuando tengamos mas recursos."

[EVENT]

weight: 2

background: none

[MESSAGE]

"No quiero molestar, pero... podemos compartir algo de comida? Hace bastante que no comemos."

[CHOICE]
text: Compartir una lata
description: Le das una lata a Silver.
requires item: canned_food
consume chance: 100%
trigger: none
rewards: none
result: Silver sonrie. "Gracias. Me hacia falta mas de lo que pensaba."

[CHOICE]
text: Decirle que espere
description: Le explicas que deben guardar las provisiones.
requires item: none
consume chance: 0%
trigger: none
rewards: none
result: "Esta bien. La guardamos para cuando sea realmente necesario."

weight: 1
background: none
