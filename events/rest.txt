# EVENTOS DE DESCANSO
# Puedes copiar un bloque [EVENT] para crear otro evento.
# Borra el # de las lineas de ejemplo solo si quieres usar esos campos.

[EVENT]
name: El visitante de la ventana
type: question
weight: 3
requires companion: no
background: none

[MESSAGE]
Un golpecito suave te despierta. Una figura pequeña flota al otro lado de la ventana.

Tiene ojos enormes y una mochila de exploración. Señala tu comida y luego se lleva una mano al estómago. Parece tener hambre.

[CHOICE]
text: Darle una lata
description: Le pasas una lata por la pequeña compuerta de intercambio.
requires item: canned_food
consume chance: 100%
trigger: none
rewards: none
result: El visitante hace una reverencia y se aleja. Por primera vez, el silencio del espacio parece amable.

[CHOICE]
text: No darle comida
description: No sabes quién es ni que quiere. Decides no compartir tus provisiones.
requires item: none
consume chance: 0%
trigger: break pod
rewards: none
result: La criatura golpea el casco con rabia antes de desaparecer. La cápsula pierde integridad.

[EVENT]
name: Lluvia de escombros
type: question
weight: 2
background: none

[MESSAGE]
Una vibración recorre la cápsula y te despierta.

Un fragmento de metal quedó enganchado cerca de una unión del casco. La integridad comienza a bajar.

[CHOICE]
text: Reparar con cinta
description: Usas cinta aislante para contener la fisura.
requires item: duct_tape
consume chance: 100%
trigger: none
rewards: none
result: La cinta aguanta. No es una reparación bonita, pero sobrevivira otra noche.

[CHOICE]
text: Ignorarlo
description: Te cubres con la manta y esperas que el casco resista.
requires item: none
consume chance: 0%
trigger: damage pod 20
rewards: none
result: El impacto termina de abrir la fisura. El aire escapa durante unos segundos.

[EVENT]
name: Una canción en el vacío
type: question
weight: 2
background: none

[MESSAGE]
La radio se enciende sola a mitad de la noche.

Una melodía muy lejana se filtra por los altavoces. En la consola aparece: "Pueden oírme?"

[CHOICE]
text: Responder a la señal
description: Envias un mensaje corto por radio.
requires item: none
consume chance: 0%
trigger: none
rewards: +1 data_core
result: La respuesta llega como un pequeño núcleo de datos. No hay voz al otro lado.

[CHOICE]
text: Apagar la radio
description: No quieres saber quién transmite.
requires item: none
consume chance: 0%
trigger: none
rewards: none
result: La melodía se desvanece y el resto de la noche transcurre en calma.

[EVENT]
name: Destellos junto a la cápsula
type: question
weight: 1
background: none

[MESSAGE]
Tres luces aparecen en la oscuridad y desaparecen.

Algo parece estar respondiendo a la señal de la linterna de la cápsula.

[CHOICE]
text: Responder con la linterna
description: Iluminas el exterior para responder a la señal.
requires item: flashlight
consume chance: 0%
trigger: none
rewards: +1 star_fragment
result: Las luces dibujan un patrón. Algo deja un fragmento brillante junto a la ventana.

[CHOICE]
text: Ignorar la señal
description: No sabes que hay ahí fuera.
requires item: none
consume chance: 0%
trigger: none
rewards: none
result: Las luces se apagan. No vuelve a ocurrir nada.
